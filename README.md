# Chess Analyzer

Настольное приложение для анализа шахматных партий на Python с использованием PySide6.

## Требования

- Python 3.10 или новее
- Зависимости из `requirements.txt`

## Запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:

   ```bash
   python main.py
   ```

## Анализ партии

На странице анализа кнопка «Анализировать партию» запускает отдельный фоновый
анализ Stockfish для ходов основной линии и вариантов PGN. Оценка ожидаемых
очков и категории ходов — приближённая модель, а не точная копия алгоритма
Chess.com. Для категории Book нужна Polyglot-база
`data/opening_book/gm2001.bin`; если файл отсутствует или повреждён, приложение
покажет предупреждение и продолжит анализ без категории Book.
Рейтинги `WhiteElo` и `BlackElo` сохраняются с партией, а отсутствующие или
некорректные значения заменяются на 1200.

Ожидаемые очки для числовой оценки Stockfish рассчитываются по непрерывной
логистической кривой Lichess WinPercent:
`E = 1 / (1 + exp(-(0.00368208 * cp + ln(10) * (Elo игрока - Elo соперника) / 400)))`.
Оценка `cp` берётся с точки зрения игрока, чей ход классифицируется; разница
рейтингов ограничена ±800, а `cp` — ±1000. Матовые оценки трактуются как
гарантированный выигрыш или проигрыш. Когда движок возвращает только WDL,
используется его доля ничьих и логистическая поправка к соотношению побед и
поражений. Модель непрерывна в решающих позициях, но не оценивает вероятность
ничьей отдельно и не воспроизводит закрытый алгоритм Chess.com; её калибровку
можно улучшить на размеченных партиях.

### Источник дебютной базы

В комплект включена бесплатная Polyglot-книга GM2001 (30 416 записей,
486 656 байт). Книга содержит партии 2001–2013 годов с рейтингом игроков не
ниже 2530; автор — Oliver Deville. Она опубликована как `gm2001.zip` в
[ChrisWhittington/polyglot-books Releases](https://github.com/ChrisWhittington/polyglot-books/releases)
и указана в credits проекта как книга из
[michaeldv/donna_opening_books](https://github.com/michaeldv/donna_opening_books),
первоначально размещённая на [Chess2U](http://www.chess2u.com/t5834p15-gm-polyglot-book).
Использование и распространение — согласно условиям автора исходной книги;
проект не заявляет авторских прав на её содержимое.
